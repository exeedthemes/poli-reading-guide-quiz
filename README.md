# POL00011 Reading Guide Quiz

Interactive exam preparation for *Politics for Rocket Scientists*.

- 110 original Reading Guide prompts converted into challenging MCQs
- 180 single-choice practice questions based on the guides and lecture slides
- Randomized 80-question mock-exam mode
- Lecture-by-lecture practice and missed-question review

Open `index.html` or use the GitHub Pages link in the repository description.
